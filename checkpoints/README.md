# Checkpoints

Download the model weights into this directory so that the final layout is:

```text
checkpoints/
├── sam3.pt
├── sam_mt.pt
└── efficienttam_s_2.pt
```

The root `README.md` contains the exact download commands for SAM3, SAM-MT, and EfficientTAM.

Checkpoint files are intentionally ignored by Git and by the Docker build context.
